MES-ERP 연동 킥오프 회의록

1차 연동 범위는 생산 실적, 자재 투입, 불량 데이터로 확정했다.
예산 1억 2천만원은 원안대로 합의했다.
2차 IoT 센서 연동 여부는 보류하고 다음 회의에서 다시 논의하기로 했다.
ERP 벤더 SLA 조건은 미정. 벤더 회신 후 결정한다.

- 김개발: API 연동 테스트 환경 구성 11월 20일까지 (긴급)
- 이기획님이 다음 주 수요일까지 요구사항 정의서 최종본을 정리해서 공유한다.
- 박팀장이 SI 인력 계약 품의를 월말까지 진행한다.
- 최영업님이 A사에 납기 정보 제공 일정을 금요일까지 전달한다.
- 벤더 담당 정과장이 API 명세서를 보내주기로 함.
